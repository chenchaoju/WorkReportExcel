# 纯前端 Excel 报工文案生成器 Spec

## Why
现场班组长每日需要根据 Excel 报工数据手动撰写汇报/提醒文案，效率低、易遗漏、易出错。提供一个零依赖、可离线打开 `index.html` 的纯前端工具：上传 Excel → 解析 → 按直属领导筛选 → 一键生成可直接复制的报工文案。

## What Changes
- 新增 `index.html` 单文件应用，使用原生 HTML + JavaScript + SheetJS (xlsx CDN)
- 实现 Excel 文件上传与解析，识别表头并映射字段
- 提供按「直属领导」多选/单选筛选
- 提供「生成类型」切换：
  - 当月报工情况
  - 今日未报工提醒
- 在页面展示生成结果，并提供「一键复制」按钮
- 不引入后端、不引入数据库、不持久化历史数据

## Impact
- Affected specs: 无（全新项目）
- Affected code: 新增 `index.html`（单文件全量交付），可放在项目根目录

## ADDED Requirements

### Requirement: Excel 文件上传与解析
系统 SHALL 提供一个文件选择/拖拽入口，支持 `.xlsx` / `.xls` 文件。

#### Scenario: 上传有效 Excel
- **WHEN** 用户选择或拖入一份表头为 `序号, 姓名/本部门, 直属领导, 报工类型, 总共报工(件数), 当月报工(件数), 当天报工(件数), 当月(来票要次), 当月(超24小时报工数), 查询日期, 最近打卡时间` 的 Excel
- **THEN** 页面自动读取全部行数据并展示在表格中，解析失败的单元格置空并保留行

#### Scenario: 上传非 Excel 文件
- **WHEN** 用户选择非 `.xlsx` / `.xls` 文件
- **THEN** 页面提示「请上传 Excel 文件 (.xlsx / .xls)」并不修改现有数据

#### Scenario: 表头缺失
- **WHEN** 上传的 Excel 缺少必要列（如 `姓名/本部门` 或 `直属领导`）
- **THEN** 页面提示具体缺失的列名并阻止后续生成操作

### Requirement: 数据展示
系统 SHALL 在页面表格中展示解析后的数据，至少包含：序号、姓名/本部门、直属领导、当月报工(件数)、当天报工(件数)、查询日期。

#### Scenario: 解析成功展示
- **WHEN** 数据解析完成
- **THEN** 表格立即渲染全部行，并提供行数统计

### Requirement: 按直属领导筛选
系统 SHALL 提供「直属领导」下拉/多选控件，默认全选，可单选或多选过滤。

#### Scenario: 单领导筛选
- **WHEN** 用户在下拉中只勾选 `叶日扬`
- **THEN** 表格与文案生成区只显示该领导下属员工

#### Scenario: 全选
- **WHEN** 用户选择「全选」
- **THEN** 恢复显示全部员工

### Requirement: 当月报工情况文案生成
系统 SHALL 在「生成类型 = 当月报工情况」时，按直属领导筛选后输出形如：
`7月份报工情况: 秦昌飞已报工98次, 唐德新已报工204次, 马作胜已报工288次, 叶运城已报工305次, 何嘉诺已报工219次。`

#### Scenario: 全部有报工
- **WHEN** 筛选范围内无 0 次人员
- **THEN** 文案列出所有人员，格式为 `XX已报工N次`，多人用 `, ` 分隔，以 `。` 结尾
- **AND** 月份从「查询日期」中取，未取到则使用当前月

#### Scenario: 存在 0 次人员
- **WHEN** 筛选范围内存在 `当月报工(件数) = 0` 的人员
- **THEN** 文案先列出未报工人员：`张三、李四当月未报工，麻烦提醒一下;`
- **AND** 同一句末尾接 `; `，再追加报工人员列表，以 `。` 结束整段

#### Scenario: 整组均为 0 次
- **WHEN** 筛选范围内所有人 `当月报工(件数) = 0`
- **THEN** 文案形如 `7月份报工情况: 张三、李四当月未报工，麻烦提醒一下。`

### Requirement: 今日未报工提醒文案生成
系统 SHALL 在「生成类型 = 今日未报工提醒」时，输出形如：
`7月8日报工情况: 张三、李四今日未报工，麻烦提醒一下。`

#### Scenario: 存在今日未报工
- **WHEN** 筛选范围内存在 `当天报工(件数) = 0` 的人员
- **THEN** 文案列出所有未报工人员，格式为 `张三、李四今日未报工，麻烦提醒一下`，以 `。` 结尾
- **AND** 日期从「查询日期」中取（如 `2026-07-08` → `7月8日`），未取到则使用当前日期

#### Scenario: 全部已报工
- **WHEN** 筛选范围内无人 `当天报工(件数) = 0`
- **THEN** 提示「当前筛选下无人今日未报工」，文案区显示为空且不允许复制

### Requirement: 一键复制
系统 SHALL 在文案区提供「一键复制」按钮，将生成的纯文本写入剪贴板。

#### Scenario: 复制成功
- **WHEN** 用户点击「一键复制」且文案非空
- **THEN** 使用 `navigator.clipboard.writeText` 写入剪贴板，按钮文案短暂变为「已复制」

#### Scenario: 复制失败兜底
- **WHEN** 浏览器剪贴板 API 不可用
- **THEN** 自动回退到 `document.execCommand('copy')` 选中文案区并执行复制，仍失败时提示手动复制

### Requirement: 纯前端与可离线
系统 SHALL 仅由一个 `index.html` 文件构成，依赖通过 CDN 引入，不强制后端服务。

#### Scenario: 本地双击打开
- **WHEN** 用户在断网或本地直接双击 `index.html`
- **THEN** 页面正常渲染；首次需联网以加载 SheetJS CDN，本地缓存后亦可使用

## MODIFIED Requirements
