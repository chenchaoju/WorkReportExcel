# Checklist

- [x] 上传 `.xlsx` / `.xls` 后能正确解析为表格
- [x] 表头缺失必要列时给出明确错误提示
- [x] 表格展示序号、姓名/本部门、直属领导、当月报工、当天报工、查询日期
- [x] 直属领导下拉默认全选，支持单选/多选过滤
- [x] 当月报工情况：全部>0 时输出 `7月份报工情况: 秦昌飞已报工98次, ...。`
- [x] 当月报工情况：存在 0 次时先输出未报工人员再接报工人员，整段以 `。` 结尾
- [x] 当月报工情况：整组为 0 时输出 `7月份报工情况: 张三、李四当月未报工，麻烦提醒一下。`
- [x] 今日未报工提醒：存在未报工时输出 `7月8日报工情况: 张三、李四今日未报工，麻烦提醒一下。`
- [x] 今日未报工提醒：无人未报工时禁用复制并提示
- [x] 文案中月份与日期从「查询日期」字段自动解析
- [x] 一键复制能成功写入剪贴板，剪贴板 API 失败时回退 `execCommand`
- [x] 单文件 `index.html`，双击可在浏览器中直接打开使用
